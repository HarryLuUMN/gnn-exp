\section{Introduction}

Graph neural networks (GNNs) have become a central modeling tool for relational data, with applications spanning social networks, molecular graphs, recommendation, traffic, and scientific discovery. Despite their broad adoption, understanding how a GNN transforms graph structure and node features into predictions remains difficult in practice. Researchers and students often inspect tensors, print intermediate activations, or rely on static plots that separate the graph, the model architecture, and the learned representations. This fragmented workflow makes it hard to connect local graph neighborhoods, message passing behavior, layer-wise feature evolution, and final predictions within a single exploratory view.

We present \textit{GNN Explorer}, an interactive visualization and explanation system for inspecting GNNs directly inside computational notebooks. The system is designed for the environments where many GNN workflows already happen: Jupyter notebooks, PyTorch, and PyTorch Geometric. Given graph data and a trained or user-defined model, GNN Explorer captures model metadata and intermediate activations, then renders linked visual representations of graph structure, adjacency patterns, layer outputs, aggregation behavior, and classifier outputs. Users can move between overview and detail by inspecting node-link and matrix views, sampling local $k$-hop subgraphs, highlighting query nodes or edges, and expanding GNN layers to examine the computations that contribute to a prediction.

GNN Explorer is implemented as a lightweight Python package backed by notebook widgets and web-based interactive views. It provides three complementary components. First, \textit{GraphVisualizer} supports dual graph exploration with node-link and matrix views, including focused subgraph extraction for larger graphs. Second, \textit{GraphEditor} allows users to modify graph structures interactively and export the edited graph data for downstream experiments. Third, \textit{GNNVisualizer} connects graph structure to model behavior by visualizing intermediate feature representations, learned weights, activation layers, graph-level pooling, and task-specific prediction flows for node classification, edge prediction, and graph classification. The current implementation supports common GNN layers including GCN, GAT, GraphSAGE, GIN, linear layers, and standard activation functions.

This demo highlights how GNN Explorer turns model inspection into an interactive, visual workflow. Rather than requiring users to move among disconnected scripts, tensor dumps, and static figures, the system keeps graph data, model internals, and explanations in the same notebook context. This design supports rapid debugging, teaching, qualitative model comparison, and communication of GNN behavior to non-expert audiences. By combining editable graph inputs, scalable rendering options, local subgraph focus, and layer-wise explanation views, GNN Explorer provides a practical interface for making GNN behavior more transparent and accessible.
