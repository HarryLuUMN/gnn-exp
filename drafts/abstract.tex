\begin{abstract}
Graph neural networks (GNNs) are powerful tools for relational data, but their behavior can be difficult to inspect in common notebook-based workflows. We demonstrate \textit{GNN Explorer}, an interactive visualization and explanation system for exploring graph structure, model internals, intermediate feature representations, and prediction pathways in one notebook-native interface. Built as a lightweight Python package with web-based widgets, GNN Explorer provides dual node-link and matrix graph views, interactive graph editing, local $k$-hop subgraph focus, and layer-wise visual explanations for PyTorch Geometric models. The system captures model metadata and intermediate activations, then links graph neighborhoods to message passing, aggregation, learned weights, pooling, and task-specific outputs. GNN Explorer supports node classification, edge prediction, and graph classification workflows, with rendering support for common GNN layers including GCN, GAT, GraphSAGE, and GIN. The demo illustrates how integrated visual inspection can make GNN debugging, teaching, qualitative comparison, and model communication more accessible.
\end{abstract}
